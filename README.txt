CubeVision X modular project

Keep every .py file and your existing PNG icons in the same folder. Also copy color_recognition.py and face_analysis.py from your original project, along with cubevision.json if used.

Install dependencies in your existing venv and run: python main.py

Modules: shared.py (theme/constants/icons), widgets.py, solver_worker.py, ui_*.py (tabs), camera.py, face_manager.py, accessibility.py, display.py, solver.py, project_data.py, shortcuts.py.
